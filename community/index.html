Community: User Stories, BDD & FRP

Work with Sean

Agency lessons. How the Sean Dinwiddie’s Webmastery team builds custom software: user stories, behavior-driven development and functional programming. Every level starts with the Introduction, and the Course Outline maps the course.

The stack follows the project: many brochure sites are easiest for owners to run on WordPress, set to update automatically, while custom apps and features that hold state follow the chain these lessons teach. Features are scoped from user stories, each story becomes a Gherkin scenario, and the scenarios drive the RTK Query endpoints, Redux Toolkit slices and minimal React views, with a Haskell (Servant) API behind them. Sean’s Functional Programming Lectures teach the functional TypeScript and Redux foundation underneath, from What Is a Function? to Modern Redux Architecture Patterns.

About us

Sean Dinwiddie’s Webmastery is a local webmastery agency working across Jefferson State — Klamath Falls, Redding, and the towns in between. Shops, restaurants, food trucks, salons, kiosks, contractors, clinics. Whether that is one person or fifty.

We build the site, get you found by the people searching nearby, and hand it over so you can run it yourself. When something breaks, you call someone who already knows your site.
