Last reviewed July 14, 2026. This page describes how this portable static site and its named providers handle data. A machine-readable processor and data-event manifest records the same behavior.

Privacy at a glance

The site works without optional analytics. Google Analytics is not requested unless you select Allow analytics. A privacy preference is stored only in your browser, and you can reopen the choice at any time with the Privacy choices button.

Hosting and ordinary requests

GitHub Pages hosts the static files. Like other hosting infrastructure, it may process ordinary request details such as an IP address, requested path, browser information, and request time under GitHub's terms. This site does not run its own application server or account database.

Optional Google Analytics

After explicit permission, the site loads Google Analytics 4 to measure page views and the limited contact events listed below. Its configuration requests IP anonymization and disables Google signals and advertising-personalization signals. Declining analytics leaves that script unloaded. Global Privacy Control or a browser Do Not Track value leaves analytics off unless you later make an explicit choice.

  • page_view: the viewed path, page title, referrer, and normal device or browser information.
  • contact_page_view: the contact-page path.
  • email_click and phone_click: the current page path, without sending the email address or telephone number as an event value.

Contact and email forms

Selecting an email or telephone link opens the software configured on your device. Information reaches Sean only if you then send a message or place a call. Some training pages contain AWeber forms. AWeber receives the name, email address, and form metadata only when you intentionally submit one of those forms; passive AWeber display pixels are removed from this static export.

External video and store content

YouTube, Vimeo, and the external store provider receive no iframe request from this site until you select the related load button. Once loaded, that provider receives normal web-request information and applies its own policy.

Your choices and questions

The browser preference uses the key sd-agency-analytics-consent. Use Privacy choices to change it, or clear this site's storage in your browser. For a question or a request concerning information you intentionally submitted, email hello@seandinwiddie.com. Provider-held information is also subject to that provider's retention and request process.
